# Course Academy – Learning Management System (LMS)

## Project Overview

Course Academy is a web-based Learning Management System designed to help students access courses and learning materials and track their learning progress.

## Main Objectives

* Organize courses and learning materials.
* Allow students to register and enroll in courses.
* Help instructors manage course content.
* Support students in tracking their learning progress.
